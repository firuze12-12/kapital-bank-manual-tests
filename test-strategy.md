# Test Strategy
Bu layihədə testlər manual şəkildə icra olunur .
Test dizayn texnikası kimi Black Box testing istifade olunur .
Test zamanı aşağıdakı ssenarilər yoxlanılır :
- Pozitiv testlər
- Negativ testlər
- Url dəyişiminin yoxlanılması
- İnput validasiyası

- Hər test case addım-addım icra olunur və sistemin davranışı müşahidə edilir .
